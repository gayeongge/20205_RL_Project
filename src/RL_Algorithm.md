# RL 알고리즘 개요

프로젝트에서 쓰는 One-Step Lookahead, N-Step Lookahead, DQN, AlphaZero-style MCTS, MTD(f)를 흐름도, 장단점, 적용 포인트로 정리했습니다.

## One-Step Lookahead
```
상태 s
  └─ 행동 a1..ak
       └─ 1수 시뮬레이션 → 휴리스틱 h(s')
             └─ argmax h → 실행 행동
```
- **아이디어:** 바로 다음 상태만 평가해 가장 높은 휴리스틱 값을 고른다.
- **복잡도:** O(branching factor B); 매우 낮은 지연(latency).
- **장점:** 초고속, 휴리스틱 디버깅·튜닝이 쉽고 결정적.
- **단점:** 지연 보상·함정에 취약, 휴리스틱 편향에 민감.
- **주 용도:** 베이스라인/롤아웃 정책, 큰 분기에서 빠른 근사, 탐색 초기 시드.
- **튜닝:** 휴리스틱 스케일 정규화, 패턴 보상·패널티 추가, 합법 수 필터링.

## N-Step Lookahead (submission_n_step_lookahead.py)
```
상태 s
  └─ 탐색 트리 (깊이 d)
       └─ 말단 평가: 휴리스틱 h(s')
             └─ 값 역전파 → 최선 수
```
- **아이디어:** `submission_n_step_lookahead.py`에서처럼 가능한 열에 내 돌을 한 번 둔 뒤, LOOKAHEAD_DEPTH(기본 3)만큼 순수 미니맥스를 돌려 휴리스틱 점수를 얻는다.
- **복잡도:** 가지수 B와 깊이 d에 대해 O(B^d). 알파-베타나 수순 정렬을 쓰지 않으므로 깊이가 커지면 비용이 급격히 증가한다.
- **장점:** 구현이 단순하고 결정적이며, `PATTERN_SCORE` 휴리스틱(내 4/3/2 연결 보너스, 상대 3/2 연결 패널티) 덕분에 짧은 전술을 빠르게 탐지한다.
- **단점:** 알파-베타 가지치기가 없어 깊이를 크게 늘리기 어렵고, 휴리스틱 품질·LOOKAHEAD_DEPTH 설정에 민감하다.
- **주 용도:** 빠른 시뮬레이터가 있고 전술 깊이를 2~4수 정도만 확장해도 충분한 ConnectX/Connect4류 환경.
- **튜닝:** LOOKAHEAD_DEPTH, 패턴 가중치, 수순 정렬(중앙 우선 등) 추가, 동일 칸 반복 방지, 휴리스틱 스케일링.

## DQN (Deep Q-Network)
```
경험 (s,a,r,s',done)
   └→ 리플레이 버퍼 (우선순위 가능)
         └→ 샘플링 → Q(s,a;θ)
         └→ 타깃 Q(s',a';θ-)로 TD 오차
                 └→ 역전파/업데이트
정책: argmax_a Q(s,a;θ) (ε-탐색)
```
- **아이디어:** 모델 없이 Q(s,a)를 신경망으로 근사, 리플레이·타깃 네트워크로 안정화.
- **장점:** 모델 불필요, 큰 상태 특징 처리, 오프-폴리시 데이터 재사용.
- **단점:** 샘플 비효율, Q 과대평가(더블 DQN으로 완화), 탐색 스케줄/버퍼 품질 민감, 결정 시 탐색 없음.
- **주 용도:** 데이터 수집이 가능하고 추론 지연을 최소화해야 할 때.
- **튜닝:** 리플레이 크기·우선순위, 타깃 네트워크 업데이트 주기, ε-스케줄, 더블/듀얼링 헤드, 보상 클리핑, 그래디언트 클리핑.

## AlphaZero-style (Policy/Value + MCTS)
```
상태 s
  └→ 정책 p(s), 가치 v(s)
        └→ MCTS 반복 (PUCT)
            - 선택: UCB/PUCT로 자식 선택
            - 확장: 새 노드 추가
            - 평가: v, 정책 prior로 초기화
            - 역전파: 값 누적
  └→ 루트 방문수 → π_MCTS → 행동 선택
학습: 자가대국(상태, π_MCTS, 최종 보상 z)로 정책/가치 망 업데이트
```
- **아이디어:** 정책·가치망으로 자가대국을 학습하고, 결정 시 정책 priors+가치로 MCTS를 가이드.
- **장점:** 탐색 집중으로 강한 수, 가치망이 롤아웃 깊이 감소, 정책 prior로 유망 수에 집중.
- **단점:** 자가대국+수마다 탐색으로 비용 높음, 정확한 시뮬레이터 필요, 커리큘럼·온폴리시 데이터 품질 중요.
- **주 용도:** 추론 시 탐색 계산을 감당하며 플레이 품질을 극대화하려는 경우.
- **튜닝:** 시뮬레이션 횟수/시간 한도, PUCT 상수, 가치/정책 로스 비율, 온도 파라미터(초기 움직임 다양화), 재연 경험 윈도 크기, 노이즈(Dirichlet) 주입.

## MTD(f)
```
초기 추정 f (직전 깊이 값 사용)
반복:
  └→ AlphaBeta(s, α=f-δ, β=f)  # 0-창
  └→ TT(전이표)에 저장
  └→ 결과에 따라 창 이동 (α/β 갱신)
수렴 → 최종 값
```
- **아이디어:** 추정값 f 주변의 0-창 알파-베타를 반복하며 TT로 재사용해 값 수렴.
- **장점:** 순수 알파-베타 대비 노드 확장 감소, 메모리 활용 극대화, 반복적 깊이 증가와 궁합.
- **단점:** 초기 추정·TT 크기·수순 정렬에 민감, TT가 작거나 정렬이 나쁘면 thrash.
- **주 용도:** 결정적 대전에서 강한 휴리스틱·수순 정렬·충분한 TT를 갖출 때.
- **튜닝:** 초기 f(직전 깊이 값), δ 설정, TT 크기·충돌 정책, 수순 정렬(역참조 테이블, killer move, history heuristic).

## 빠른 비교
| 알고리즘 | 결정 시 모델 | 탐색/검색 | 학습 | 메모리 요구 | 지연 | 강점 |
| --- | --- | --- | --- | --- | --- | --- |
| One-Step | 예 | 1수 | 없음 | 매우 낮음 | 매우 낮음 | 초고속, 단순 |
| N-Step | 예 | 깊이 d (α-β) | 없음 | 낮음~중간 | 깊이에 따라 증가 | 전술 커버, 결정적 |
| DQN | 아니오 | 없음 (정책 추론) | 예 (가치망) | 중간(버퍼) | 매우 낮음 | 데이터 재사용, 저지연 |
| AlphaZero+MCTS | 예 | 가변(MCTS) | 예 (정책/가치) | 중~높음 | 중~높음 | 탐색 기반 강수 |
| MTD(f) | 예 | 가변(반복 0-창) | 없음(휴리스틱) | 높음(TT) | 중간 | 결정적 게임 효율 |

## 선택 가이드
- **극저지연·계산 예산 최소:** One-Step Lookahead.
- **전술적 깊이 필요, 결정적 환경:** N-Step + α-β + 수순 정렬 + (옵션) TT.
- **데이터 풍부, 탐색 없이 정책 필요:** DQN(더블/듀얼링/우선순위 리플레이 고려).
- **추론 시 탐색 허용, 최고 품질 목표:** AlphaZero-style MCTS(정책/가치 학습 + 적절한 시뮬레이션 횟수).
- **결정적 대전, TT/정렬을 갖춘 고효율 탐색:** MTD(f) + Iterative Deepening.
