## 파일별 상세

### `mtdf_zobrist_baseline.py` (기존 `mtd_f.py`)
- **개선 배경.** 기본 minimax의 동일 상황 중복 계산과 메모리 비효율을 해결하기 위해 MTD(f) + Zobrist 해싱 도입한 기준선 구현.
- **핵심 특징.**
  - `init_zobrist()`로 64비트 해시 테이블 초기화, `TT` 전이표로 중복 계산 방지
  - **전략적 점수 체계**: 상대 3목 -20M(무조건 막아라), 내 3목 +100K, 상대 2목 -40K(미리 끊어라) 등 우선순위 명확화
  - `detect_gap_threats()`로 징검다리 패턴(X-O-X-빈칸) 감지하여 숨겨진 위협 조기 차단
  - 중앙 점령 +10점으로 포지셔널 어드밴티지 확보
- **한계.** player/root_player 비교 방식으로 부호 혼동 발생 가능성, 시간 초과시 미완료 탐색 결과 반환으로 품질 저하.

### `mtdf_negamax_stable.py` (기존 `mtd_f_negamax.py`)
- **개선 배경.** 기본 MTD(f)에서 발생하던 부호 관련 버그와 시간 관리 불안정성을 negamax 알고리즘 도입으로 근본 해결.
- **핵심 특징.**
  - **Negamax 전환**: 항상 현재 플레이어 관점에서 점수 계산, 재귀 호출시 `-score`로 관점 전환하여 부호 오류 완전 제거
  - **안전한 시간 관리**: `try-except TimeoutError`로 미완료 깊이 대신 이전 완료된 깊이 결과 사용 (safe-fail)
  - **강화된 방어 체계**: 상대 킬각 방어 50M점으로 승리급 중요도 부여, 징검다리 위협 500K로 전술적 우선순위 강화
  - **점수 체계 부호 정리**: SCORE_LOSS -1억으로 설정, negamax가 상대 공격 차단을 엄청난 이득으로 정확히 판단
- **성능 결과**: negamax 에이전트와의 대전에서 0% → 100% 승률로 극적 개선
- **한계.** 높이 최적화 없어 동일 효과의 승리수 중 비효율적 선택 가능, 자살수(상대에게 승리 기회 제공) 방지 기능 부재.

### `mtdf_negamax_strategic.py` (기존 `mtd_f_negamax_nf.py`)
- **개선 배경.** negamax 안정성 확보 후 실전 게임에서 요구되는 전술적 세밀함 - 효율적 승리와 위험 회피를 동시 구현.
- **핵심 특징.**
  - **높이 최적화 승리**: `get_column_height()`로 승리 가능 열 중 가장 낮은 높이 우선 선택하여 여유있는 승리 추구
  - **자살수 방지**: `check_suicide_move()`로 내 수가 상대에게 즉시 승리 기회를 주는지 검사하여 위험한 수 완전 배제
  - **하이브리드 의사결정**: 크리티컬 블록킹을 1순위로, MTD(f) 탐색을 2순위로 하여 안전성과 전략성 균형
  - **간소화된 점수체계**: 승리/패배/중앙만 유지하여 계산 복잡도 감소하면서도 핵심 전략 보존
- **한계.** 자살수 검사와 높이 계산으로 수당 연산량 증가, 점수체계 단순화로 미세한 포지셔널 어드밴티지 놓칠 가능성.

## 🏆 전략적 점수 체계 (Scoring System)

MTD(f)의 정적 평가 함수에서 사용하는 전략적 점수들은 탐색 엔진이 "어떤 상태가 유리한지" 판단하는 핵심 기준입니다:

### 승리/패배 (Game Over)
- **내 승리** (4목 완성): +1,000,000,000 (10억 점 / 절대적)
- **상대 승리** (4목 허용): -1,000,000,000 (-10억 점 / 절대적)

### 치명적 위협 (Critical Threat) - "무조건 막아라"
- **상대 3개 + 빈칸 1개** (연속/징검다리 포함): -20,000,000
- 상대가 다음 수에 끝낼 수 있는 상태로, 내 공격 점수보다 패배 방어 점수의 비중을 훨씬 높게 잡아 무조건 막도록 강제

### 강력한 기회 (Major Opportunity)  
- **내 3개 + 빈칸 1개**: +100,000
- 상대를 압박하여 방어를 강요하거나 승리로 연결되는 기회

### 잠재적 위협/기회 (Potential) - "미리 끊어라"
- **상대 2개 + 빈칸 2개**: -40,000
- 상대가 2개일 때 미리 끊어주는 플레이에 높은 가중치 부여 (단순 연결 점수보다 훨씬 높음)

### 기초 점수 (Positional)
- **내 2개**: +1,000
- **중앙 점령**: +10 (중앙에 가까울수록 유리)

**더블 위협 (Double Threat)**: MTD(f) 탐색 알고리즘이 수읽기를 통해 자동으로 양수겸장 상황을 찾아내므로 별도 점수 없이도 +100,000 이상의 가치로 판단

## 📊 성능 평가 결과

### 초기 버전 (mtd_f.py) 성능
```
=== Evaluation vs negamax ===
Player 1 wins: 0, Player 2 wins: 10, Win rate: 0.0%
```

### Negamax 전환 후 (mtdf_negamax_stable.py) 성능  
```
=== Evaluation vs negamax ===
Player 1 wins: 10, Player 2 wins: 0, Win rate: 100.0%
```

**💡 핵심 개선 포인트**:
1. **Negamax 전환**: player/root_player 비교 방식 → 현재 플레이어 관점 점수 계산으로 부호 오류 완전 제거
2. **안전한 시간 관리**: 타임아웃시 미완료 결과 대신 완벽히 끝난 이전 깊이 결과 사용
3. **점수 체계 부호 정리**: negamax가 상대 공격 차단을 올바르게 최고 우선순위로 판단

## 실무 관점 메모
1. **학습/연구 목적**이면 `mtdf_zobrist_baseline.py`가 MTD(f)와 전이표의 기본 개념을 가장 명확히 보여줌.
2. **안정적인 강화**가 필요하면 `mtdf_negamax_stable.py`가 부호 오류 없는 negamax 기반으로 신뢰할 수 있음.
3. **실전 경쟁**이 목표라면 `mtdf_negamax_strategic.py`가 자살수 방지와 높이 최적화로 가장 완성도 높은 플레이 제공.
4. **성능 vs 품질** 트레이드오프: baseline → stable → strategic 순으로 계산량 증가하지만 게임 품질도 향상.
